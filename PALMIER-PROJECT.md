# palmier-project

本專案在本機與 Codex 中統一使用名稱：`palmier-project`。

## 建議下載方式

```bash
git clone -b feature/palmier-video-lab https://github.com/SimonHuangTPE/claude-code-image-skills.git palmier-project
cd palmier-project
bash palmier/scripts/install-local.sh
```

這樣下載後的資料夾名稱會直接顯示為：

```text
palmier-project
```

## Codex 開啟

在 Codex 選擇本機資料夾：

```text
palmier-project
```

或開啟：

```text
palmier-project.code-workspace
```

## 主要入口

- `palmier/README.md`
- `palmier/skills/palmier-video-edit/SKILL.md`
- `palmier/templates/60s-vertical-short.prompt.md`
- `palmier/benchmark/acceptance-test.md`
